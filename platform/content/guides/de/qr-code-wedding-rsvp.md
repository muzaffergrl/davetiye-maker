Mit einem QR-Code antworten Gäste in Sekunden vom Handy, statt eine Adresse abzutippen. Er schafft aber auch eine neue Fehlerquelle, nachdem die Karten gedruckt sind: einen Code, der nicht mehr funktioniert, die falsche Seite öffnet oder sich in einem dunklen Saal nicht scannen lässt. Dieser Ratgeber behandelt die Entscheidungen, auf die es ankommt: worauf der Code zeigen soll, wie groß Sie ihn drucken, was Sie vermeiden sollten und wie Sie ihn testen.

Unser Ratgeber, [die Hochzeitswebsite auf die Einladung zu bringen](/guides/wedding-website-on-invitation), erklärt, wohin der Code in der Einladungspapeterie gehört, und enthält eine grundlegende Druck-Checkliste. Diese Seite geht einen Schritt weiter.

## Statisch oder dynamisch: Funktioniert der Code in einem Jahr noch?

Es gibt zwei Arten von QR-Codes, und der Unterschied zeigt sich erst, wenn es zu spät ist:

| | Statischer Code | Dynamischer (Weiterleitungs-)Code |
|---|---|---|
| Was er enthält | Ihre Website-Adresse selbst | Einen Kurzlink des QR-Generators, der auf Ihre Adresse weiterleitet |
| Funktioniert ohne den Generator | Ja, solange Ihre Website online ist | Nein; endet der kostenpflichtige Tarif oder die Testphase des Generators, kann der Code ausfallen |
| Ziel nach dem Druck änderbar? | Nein | Ja, solange der Tarif läuft |
| Zählt Scans | Nein | Oft ja |
| Am besten für | Gedruckte Hochzeitskarten | Marketingkampagnen mit wechselndem Ziel |

Für eine Hochzeit ist ein statischer Code meist die sicherere Wahl. Viele kostenlose Generatoren erstellen standardmäßig dynamische Codes, und manche leiten nach einer Testphase nicht mehr weiter. Scannen Sie den Code vor dem Druck und prüfen Sie, ob die angezeigte Adresse Ihre eigene Website ist und nicht die des Generators.

Wählen Sie einen statischen Code, darf sich die enthaltene Adresse nicht ändern. Legen Sie zuerst Ihre Website-Adresse fest und erstellen Sie dann den Code.

## Welche Seite soll er öffnen?

Lassen Sie den Code auf die Seite zeigen, die Gäste am meisten brauchen:

- **Die Hauptadresse Ihrer Website** ist die sicherste Wahl. Sie funktioniert für die Einladung, die Details und das Antwortformular und ist dieselbe Adresse, die Sie als Text drucken.
- **Direkt die Antwortseite** spart einen Tipp; schließt das Antwortformular aber nach Ihrer RSVP-Frist, führt der Code zu einem geschlossenen Formular.
- **Ein Formular bei einem anderen Dienst** verteilt Ihre Informationen auf zwei Orte und bringt eine weitere Adresse, die sich ändern kann.

Auf einer Antwortkarte funktioniert die Hauptadresse mit dem Hinweis „Zum Antworten scannen“ gut, solange das Antwortformular vom ersten Bildschirm aus leicht zu finden ist.

## Wie groß sollte ein QR-Code für die Hochzeit sein?

Eine verbreitete Faustregel besagt, dass sich ein Code aus etwa dem Zehnfachen seiner Breite scannen lässt. Sehr lange Adressen ergeben dichtere Codes, die für zuverlässiges Scannen mehr Platz brauchen.

| Wo er gedruckt wird | Typischer Scanabstand | Empfohlene Größe |
|---|---|---|
| Einladung, Info- oder Antwortkarte | 15–25 cm, in der Hand | 2,5–3 cm (1–1,2 Zoll) |
| Tischkarte oder Platzkarte | 30–50 cm | 4–5 cm (1,5–2 Zoll) |
| Willkommensschild auf einer Staffelei | 1–2 m | 10–20 cm (4–8 Zoll) |
| Plakat oder Bildschirm quer durch den Raum | 3 m oder mehr | 30 cm (12 Zoll) oder mehr |

Diese Größen sind ohne Rand gerechnet. Ergänzen Sie rund um den Code einen freien weißen Rand: DENSO WAVE, der Erfinder des Codes, gibt eine [Ruhezone von vier Modulen](https://www.qrcode.com/en/howto/code.html) auf jeder Seite vor.

## Logos, Farben und andere Gestaltungsrisiken

Gestalter passen QR-Codes gern der Einladung an. Manche Änderungen sind sicher; andere führen dazu, dass der Code auf manchen Handys versagt.

- **Ein Logo oder Monogramm in der Mitte.** QR-Codes können fehlende Teile über Fehlerkorrektur wiederherstellen. DENSO WAVE nennt [vier Stufen](https://www.qrcode.com/en/about/error_correction.html), von L (etwa 7 % der Daten wiederherstellbar) bis H (etwa 30 %). Ein Logo verbraucht diese Reserve, sodass ein Knick oder Fleck obendrauf den Code unlesbar machen kann. Wenn Sie eines einfügen, nutzen Sie Stufe H, halten Sie das Logo klein und testen Sie die gedruckte Karte.
- **Goldfolie, Metallic- oder Glanzfarbe.** Spiegelungen verdecken bei Innenlicht Teile des Codes. Drucken Sie den Code in matter Farbe.
- **Heller Code auf dunkler Karte.** Viele Handykameras lesen ihn trotzdem, aber nicht alle. Ein dunkler Code auf hellem Grund ist die zuverlässige Wahl.
- **Kontrastarme Farben.** Ein blasses Salbeigrün oder Rosé auf elfenbeinfarbenem Papier lässt sich womöglich nicht scannen. Halten Sie den Code dunkel genug, dass er auf einen Blick klar zu lesen ist.
- **Runde Punkte und verzierte Ecken.** Manche Generatoren erlauben sie; testen Sie gründlich, denn ältere Handys können Probleme haben.

## Schilder an der Location

Am Hochzeitstag ist ein QR-Code nützlich für den Ablauf, einen Link zum Hochladen von Fotos oder das Menü. Machen Sie ihn leicht nutzbar:

- [ ] Drucken Sie ihn groß genug für den Abstand (siehe Tabelle oben)
- [ ] Bringen Sie ihn auf Brusthöhe an, nicht über einem Tisch oder hinter Blumen
- [ ] Beleuchten Sie ihn: In Räumen mit Kerzenlicht lassen sich Codes schwer scannen
- [ ] Nehmen Sie eine matte Oberfläche, keine glänzende Laminierung, die Licht spiegelt
- [ ] Schreiben Sie eine Zeile dazu, wofür er ist: „Scannen für den Ablauf des Abends“
- [ ] Testen Sie ihn vor Ort bei der abendlichen Beleuchtung, bevor die Gäste kommen

## Drucken Sie immer auch die Adresse

Manche Gäste scannen keinen Code: ältere Verwandte, Gäste mit älteren Handys oder alle, die lieber tippen. Drucken Sie neben jeden Code die geschriebene Adresse und halten Sie sie kurz genug, um sie vorzulesen. Ein Code ohne geschriebene Adresse lässt diese Gäste ohne Zugang.

Hat Ihre Website ein Gäste-Passwort, drucken Sie es ebenfalls neben den Code, sonst bleiben Gäste nach dem Scannen auf der Passwortseite stehen. Unser Ratgeber zum [Datenschutz der Hochzeitswebsite](/guides/wedding-website-privacy) erklärt, wann sich ein Passwort lohnt.

## Vor dem Druck testen

1. Erstellen Sie den Code aus Ihrer endgültigen Adresse.
2. Drucken Sie ein Exemplar in Originalgröße auf dem echten Papier, oder lassen Sie sich von der Druckerei einen gedruckten Probeabzug geben.
3. Scannen Sie es mit mindestens zwei verschiedenen Handys, am besten auch einem älteren Modell.
4. Prüfen Sie, ob die richtige Seite öffnet und das Antwortformular funktioniert, wenn Sie eine Testantwort senden.
5. Löschen Sie die Testantwort, bevor Sie Gäste einladen, sofern Ihre Plattform das zulässt.

Für die Fragen im Antwortformular selbst lesen Sie, [welche RSVP-Fragen sinnvoll sind](/guides/wedding-rsvp-questions).

## FAQ

### Sollten wir für unsere Hochzeit einen kostenlosen QR-Code-Generator nutzen?

Das geht, wenn er einen statischen Code mit Ihrer eigenen Website-Adresse erstellt. Meiden Sie Codes, die über den eigenen Kurzlink des Generators weiterleiten, denn manche funktionieren nach dem Ende einer Testphase oder eines kostenpflichtigen Tarifs nicht mehr. Scannen Sie den Code vor dem Druck und prüfen Sie, welche Adresse er zeigt.

### Wie groß sollte ein QR-Code auf der Hochzeitseinladung sein?

Mindestens 2,5 cm (1 Zoll) im Quadrat auf einer Karte, die man in der Hand hält, plus ein freier weißer Rand ringsum. Auf Schildern größer: Nach einer verbreiteten Faustregel lässt sich ein Code aus etwa dem Zehnfachen seiner Breite scannen.

### Können wir unser Monogramm in die Mitte des QR-Codes setzen?

Das geht, aber es verbraucht die Fehlerkorrektur des Codes, sodass ein Knick oder Fleck ihn dann ausfallen lassen kann. Wenn Sie es einfügen, wählen Sie die höchste Fehlerkorrekturstufe, halten Sie das Monogramm klein und testen Sie die gedruckte Karte mit mehreren Handys.

### Soll der RSVP-QR-Code das Antwortformular oder die Website öffnen?

Die Hauptadresse der Website ist meist sicherer. Sie zeigt Gästen die Details, bevor sie antworten, entspricht der geschriebenen Adresse und funktioniert auch noch, wenn das Antwortformular geschlossen ist. Achten Sie darauf, dass das Antwortformular vom ersten Bildschirm aus leicht zu finden ist.
