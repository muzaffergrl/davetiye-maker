Ihre Hochzeitswebsite hilft nur, wenn Gäste sie finden. Bei einer digitalen Einladung ist das einfach: Der Link steht in der Nachricht. Bei einer Papiereinladung müssen Sie entscheiden, wohin die Adresse kommt, wie Sie sie formulieren und ob ein QR-Code dazugehört. Dieser Ratgeber behandelt alle drei Fragen, mit Formulierungen zum Übernehmen.

## Wohin die Website-Adresse gehört

Die eigentliche Einladungskarte ist das förmlichste Stück Ihrer Papeterie. Etikette-Ratgeber, darunter das [Emily Post Institute](https://emilypost.com/advice/wedding-website-tips), empfehlen, die Website-Adresse nicht darauf zu drucken, sondern auf eine andere Karte im Umschlag. Viele moderne Paare drucken stattdessen eine dezente Zeile ganz unten auf die Einladung; das ist eine Stilfrage, kein Fehler. Ist Ihre Einladung förmlich, nehmen Sie eine separate Karte.

| Stück | Website darauf? | Wie |
|---|---|---|
| Save-the-Date | Ja, wenn die Seite schon online ist | Die Adresse in eigener Zeile, mit „Einladung folgt“ |
| Eigentliche Einladungskarte | Traditionell nein | Wenn doch, eine kleine Zeile ganz unten |
| Infokarte (Beilage) | Ja, das ist der übliche Platz | Die Adresse, ein QR-Code und was Gäste dort finden |
| Antwortkarte | Ja, wenn Gäste online antworten | „Wir bitten um Antwort bis zum 15. Mai 2027 unter“ und die Adresse |
| Umschlag | Nein | Lassen Sie die Außenseite für Namen und Anschriften |
| Nachricht zur digitalen Einladung | Ja | Der Link selbst, mit einem persönlichen Satz |

Zwei Regeln machen es einfach:

- **Ein Ort zum Antworten.** Antworten Gäste online, sollte die Antwortkarte sie zur Website schicken, statt sie zusätzlich eine Karte per Post zurückschicken zu lassen. Zwei Antwortwege bedeuten zwei Listen, die Sie zusammenführen müssen.
- **Angaben zur Wunschliste gehören auf die Website, nicht aufs Papier.** Nach Emily Post haben Wunschlisten-Angaben auf der Einladung und ihren Beilagen nichts zu suchen; die Website ist der richtige Ort dafür.

## Formulierungen zum Übernehmen

Wählen Sie den Ton Ihrer Einladung und bleiben Sie dabei. Schreiben Sie die Antwortfrist vollständig aus, mit dem Monat als Wort, damit Gäste in anderen Ländern sie gleich lesen. Unser Ratgeber zu [Texten für die Hochzeitswebsite](/guides/wedding-website-wording) hat weitere Beispiele für die Seiten selbst.

**Infokarte, förmlich**

*„Alle Einzelheiten zum Tag, zu Unterkünften und zur Anreise finden Sie unter (Ihre Adresse).“*

**Infokarte, locker**

*„Alles, was ihr wissen müsst (Ablauf, Hotels und Dresscode), steht auf unserer Website: (Ihre Adresse)“*

**Antwortkarte, förmlich**

*„Wir bitten um Ihre Antwort bis zum 15. Mai 2027 unter (Ihre Adresse).“*

**Antwortkarte, locker**

*„Sagt uns bis zum 15. Mai 2027 Bescheid! Antwortet unter (Ihre Adresse) oder scannt den Code.“*

**Save-the-Date**

*„Save the Date: Clara und Julian heiraten am 12. Juni 2027 in Florenz. Einladung folgt. (Ihre Adresse)“*

**Kleine Zeile unten auf der Einladung**

*„Details und Zusage: (Ihre Adresse)“*

Hat Ihre Website ein Gäste-Passwort, drucken Sie es auf die Infokarte, nicht auf die Einladung: *„Passwort: (Ihr Passwort)“*. Wer die Karte in der Hand hält, kann die Seite öffnen, und das sind meist genau die Menschen, die Sie meinen.

## Link, QR-Code oder beides?

Drucken Sie beides. Sie helfen unterschiedlichen Gästen:

- **Eine geschriebene Adresse** funktioniert für alle, auch für Gäste, die sie am Computer eintippen, und für die, die keine Handykamera nutzen. Halten Sie sie kurz und leicht vorzulesen: Ihre Namen, keine ungewöhnlichen Schreibweisen, keine langen Zahlenreihen.
- **Ein QR-Code** erspart das Tippen am Handy. Die meisten Handykameras öffnen einen QR-Code ohne zusätzliche App.

Schreiben Sie ein paar Worte neben den Code, damit Gäste wissen, wofür er ist: „Scannen für Details und Zusage“. Ein Code ohne Beschriftung wirkt wie Dekoration.

## Einen QR-Code drucken, der sich scannen lässt

QR-Codes scheitern auf Papier an einer Handvoll vorhersehbarer Gründe. Prüfen Sie jeden davon, bevor Sie die ganze Auflage drucken:

- [ ] Erstellen Sie den Code aus Ihrer endgültigen Adresse und öffnen Sie ihn zuerst auf Ihrem eigenen Handy
- [ ] Drucken Sie ihn auf einer Karte, die man in der Hand hält, etwa 2,5 cm (1 Zoll) im Quadrat oder größer
- [ ] Lassen Sie rundherum einen freien weißen Rand; DENSO WAVE, der Erfinder des Codes, gibt einen [Rand von vier Modulen](https://www.qrcode.com/en/howto/code.html) auf jeder Seite vor, in den nichts gedruckt wird
- [ ] Verwenden Sie einen dunklen Code auf hellem Grund, nie Goldfolie auf Creme oder einen hellen Code auf dunkler Karte
- [ ] Setzen Sie ihn nicht über einen Falz, eine Struktur oder ein Muster
- [ ] Verwenden Sie eine Vektordatei (SVG) oder ein hochauflösendes Bild (PNG), damit die Kanten scharf bleiben
- [ ] Scannen Sie den gedruckten Probeabzug bei normalem Raumlicht mit zwei verschiedenen Handys
- [ ] Stellen Sie sicher, dass die Adresse, die er öffnet, bis nach der Hochzeit gleich bleibt

Der letzte Punkt ist wichtiger, als er aussieht. Ein Code, der auf zweihundert Karten gedruckt ist, lässt sich nicht mehr ändern. Ziehen Sie mit Ihrer Website vielleicht später um, nutzen Sie eine Adresse, die Sie so lange kontrollieren, wie Gäste sie brauchen, keinen vorübergehenden Link.

## Digitale Einladungen: Der Link ist die Einladung

Wenn Sie die Einladung per SMS, WhatsApp oder E-Mail verschicken, trägt der Website-Link alles. Ein paar Gewohnheiten helfen:

1. **Schicken Sie jedem Gast eine persönliche Nachricht**, keine Gruppennachricht. Beginnen Sie mit seinem Namen.
2. **Prüfen Sie die Linkvorschau**, indem Sie den Link zuerst an sich selbst schicken. Sie sollte Ihre Namen oder ein Bild zeigen, kein leeres Feld.
3. **Sagen Sie, wofür der Link ist**: „Hier ist unsere Einladung, mit allen Details und dem Antwortformular“.
4. **Schicken Sie eine Woche vor der Antwortfrist eine Erinnerung** an Gäste, die noch nicht geantwortet haben.

Unser Ratgeber dazu, [wann Sie Ihre Hochzeitswebsite teilen](/guides/when-to-send-your-wedding-website), zeigt das Timing für Save-the-Dates, Einladungen und Erinnerungen.

## Häufige Fehler

- **Drucken, bevor die Website fertig ist.** Gäste, die in der ersten Woche scannen, sollten mindestens die Namen, das Datum und den Ort finden.
- **Eine Adresse, die schwer auszusprechen ist.** Können Sie sie einer Großmutter am Telefon nicht vorlesen, kürzen Sie sie.
- **Verschiedene Adressen auf verschiedenen Karten.** Drucken Sie überall dieselbe Adresse.
- **Kein Datum in der Antwortzeile.** „Bitte online zusagen“ ohne Datum bringt späte Antworten.
- **Zu viel Text um den Code.** Eine kurze Beschriftung reicht; die Details gehören auf die Website.

## FAQ

### Ist es unhöflich, die Hochzeitswebsite auf die Einladung zu schreiben?

Unhöflich nicht, aber die klassische Etikette lässt sie von der eigentlichen Einladungskarte weg und setzt sie auf eine Infokarte oder die Antwortkarte. Eine kleine Zeile unten auf einer modernen Einladung ist weithin akzeptiert. Bei einer förmlichen Einladung nehmen Sie eine separate Karte.

### Wohin gehört der QR-Code auf einer Hochzeitseinladung?

Auf die Infokarte oder die Antwortkarte, neben die geschriebene Adresse und eine kurze Beschriftung wie „Scannen für Details und Zusage“. Meiden Sie Falze, Strukturen und Goldfolie und lassen Sie einen freien weißen Rand um den Code, damit Handykameras ihn lesen können.

### Gehört die Website auf das Save-the-Date?

Ja, wenn die Seite schon die Namen, das Datum und den Ort zeigt. Ergänzen Sie den Hinweis, dass die Einladung folgt. Gäste können dann für Hotels und Anreise nachsehen, sobald Sie diese ergänzen.

### Was, wenn sich unsere Website-Adresse nach dem Druck ändert?

Vermeiden Sie das, indem Sie vor dem Druck eine Adresse wählen, die bis nach der Hochzeit gleich bleibt. Ändert sie sich doch, schicken Sie jedem Gast den neuen Link in einer persönlichen Nachricht und lassen Sie die alte Adresse weiter funktionieren, wenn Ihre Plattform das erlaubt.
