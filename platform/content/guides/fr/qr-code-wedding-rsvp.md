Un QR code permet aux invités de répondre depuis leur téléphone en quelques secondes au lieu de taper une adresse. Mais il crée aussi une nouvelle source d'erreur une fois les cartes imprimées : un code qui cesse de fonctionner, ouvre la mauvaise page ou ne se lit pas dans une salle sombre. Ce guide passe en revue les décisions qui comptent : vers quoi le code doit pointer, à quelle taille l'imprimer, ce qu'il faut éviter et comment le tester.

Notre guide pour [indiquer son site de mariage sur le faire-part](/guides/wedding-website-on-invitation) explique où placer le code dans la papeterie et propose une liste de base pour l'impression. Cette page va un peu plus loin.

## Statique ou dynamique : le code marchera-t-il encore dans un an ?

Il existe deux types de QR codes, et la différence n'apparaît que quand il est trop tard :

| | Code statique | Code dynamique (avec redirection) |
|---|---|---|
| Ce qu'il contient | L'adresse de votre site elle-même | Un lien court appartenant au générateur, qui redirige vers votre adresse |
| Fonctionne sans le générateur | Oui, tant que votre site est en ligne | Non ; si l'offre payante ou l'essai du générateur prend fin, le code peut cesser de fonctionner |
| Peut-on changer la destination après l'impression ? | Non | Oui, tant que l'offre est active |
| Compte les scans | Non | Souvent |
| Idéal pour | Les cartes de mariage imprimées | Les campagnes marketing dont la destination change |

Pour un mariage, un code statique est généralement le choix le plus sûr. Beaucoup de générateurs gratuits créent des codes dynamiques par défaut, et certains cessent de rediriger après une période d'essai. Avant d'imprimer, scannez le code et vérifiez que l'adresse affichée est celle de votre site, et non celle du générateur.

Si vous choisissez un code statique, l'adresse qu'il contient ne doit pas changer. Fixez d'abord l'adresse de votre site, puis créez le code.

## Quelle page doit-il ouvrir ?

Faites pointer le code vers la page dont les invités ont le plus besoin :

- **L'adresse principale de votre site** est le choix le plus sûr. Elle sert pour l'invitation, les détails et le formulaire de réponse, et c'est la même adresse que celle que vous imprimez en texte.
- **Directement la page de réponse** fait gagner un geste, mais si le formulaire ferme après votre date limite, le code mène à un formulaire fermé.
- **Un formulaire sur un autre service** répartit vos informations à deux endroits et ajoute une adresse de plus qui peut changer.

Sur le carton-réponse, l'adresse principale avec la mention « Scannez pour répondre » fonctionne bien, à condition que le formulaire soit facile à trouver dès le premier écran.

## Quelle taille pour un QR code de mariage ?

Une règle empirique répandue veut qu'un code se scanne à environ dix fois sa largeur. Les adresses très longues donnent des codes plus denses, qui ont besoin de plus de place pour être lus de façon fiable.

| Où il est imprimé | Distance de scan habituelle | Taille conseillée |
|---|---|---|
| Faire-part, carte d'informations ou carton-réponse | 15–25 cm, tenu en main | 2,5–3 cm (1–1,2 pouce) |
| Carte de table ou marque-place | 30–50 cm | 4–5 cm (1,5–2 pouces) |
| Panneau de bienvenue sur un chevalet | 1–2 m | 10–20 cm (4–8 pouces) |
| Affiche ou écran à l'autre bout de la salle | 3 m ou plus | 30 cm (12 pouces) ou plus |

Ces tailles ne comprennent pas la marge. Ajoutez une bordure blanche nette autour du code : son créateur, DENSO WAVE, prévoit une [zone de silence de quatre modules](https://www.qrcode.com/en/howto/code.html) de chaque côté.

## Logos, couleurs et autres risques de design

Les graphistes aiment assortir le QR code au faire-part. Certaines modifications sont sans risque ; d'autres font échouer le code sur certains téléphones.

- **Un logo ou un monogramme au centre.** Les QR codes peuvent reconstituer les parties manquantes grâce à la correction d'erreurs. DENSO WAVE en décrit [quatre niveaux](https://www.qrcode.com/en/about/error_correction.html), de L (environ 7 % des données récupérables) à H (environ 30 %). Un logo consomme cette marge, si bien qu'un pli ou une tache par-dessus peut rendre le code illisible. Si vous en ajoutez un, choisissez le niveau H, gardez le logo petit et testez la carte imprimée.
- **Dorure, encre métallisée ou brillante.** Les reflets masquent des parties du code sous un éclairage intérieur. Imprimez le code en encre mate.
- **Code clair sur carte foncée.** Beaucoup d'appareils photo le lisent quand même, mais pas tous. Un code foncé sur fond clair est le choix fiable.
- **Couleurs peu contrastées.** Un code vert sauge pâle ou rose poudré sur papier ivoire risque de ne pas se scanner. Gardez le code assez foncé pour qu'il se lise clairement d'un coup d'œil.
- **Points arrondis et coins décoratifs.** Certains générateurs le permettent ; testez soigneusement, car les téléphones anciens peuvent avoir du mal.

## Les panneaux sur le lieu

Le jour J, un QR code est pratique pour le programme, un lien de dépôt de photos ou le menu. Facilitez-en l'usage :

- [ ] Imprimez-le assez grand pour la distance (voir le tableau ci-dessus)
- [ ] Placez-le à hauteur de poitrine, pas au-dessus d'une table ni derrière des fleurs
- [ ] Éclairez-le : dans une salle aux bougies, les codes sont difficiles à scanner
- [ ] Choisissez une finition mate, pas une plastification brillante qui reflète la lumière
- [ ] Écrivez une ligne qui explique son rôle : « Scannez pour le programme de la soirée »
- [ ] Testez-le dans la salle, avec l'éclairage du soir, avant l'arrivée des invités

## Imprimez toujours l'adresse aussi

Certains invités ne scannent pas : des proches âgés, des invités aux téléphones anciens ou tous ceux qui préfèrent taper. Imprimez l'adresse écrite à côté de chaque code, et gardez-la assez courte pour être lue à voix haute. Un code sans adresse écrite laisse ces invités sans moyen d'accéder au site.

Si votre site a un mot de passe invités, imprimez-le aussi à côté du code, sinon ceux qui scannent s'arrêteront sur la page du mot de passe. Notre guide sur la [confidentialité du site de mariage](/guides/wedding-website-privacy) explique quand un mot de passe vaut la peine.

## Testez avant d'imprimer

1. Générez le code à partir de votre adresse définitive.
2. Imprimez un exemplaire à sa taille réelle sur le vrai papier, ou demandez une épreuve physique à l'imprimeur.
3. Scannez-le avec au moins deux téléphones différents, idéalement dont un ancien modèle.
4. Vérifiez qu'il ouvre la bonne page et que le formulaire fonctionne en envoyant une réponse test.
5. Supprimez la réponse test avant d'inviter qui que ce soit, si votre plateforme le permet.

Pour les questions du formulaire lui-même, voyez [quelles questions RSVP poser](/guides/wedding-rsvp-questions). Pour le papier, les fonds perdus et les enveloppes, voyez comment [imprimer ses faire-part de mariage chez soi ou chez l'imprimeur](/guides/print-wedding-invitations-at-home).

## FAQ

### Peut-on utiliser un générateur de QR code gratuit pour notre mariage ?

Oui, s'il crée un code statique contenant l'adresse de votre propre site. Évitez les codes qui redirigent par le lien court du générateur, car certains cessent de fonctionner à la fin d'un essai ou d'une offre payante. Scannez le code avant d'imprimer et vérifiez l'adresse qu'il affiche.

### Quelle taille pour un QR code sur un faire-part de mariage ?

Au moins 2,5 cm (1 pouce) de côté sur une carte tenue en main, plus une marge blanche nette tout autour. Prévoyez plus grand sur les panneaux : selon une règle empirique répandue, un code se scanne à environ dix fois sa largeur.

### Peut-on mettre notre monogramme au centre du QR code ?

Oui, mais il consomme la correction d'erreurs du code, si bien qu'un pli ou une tache peut alors le faire échouer. Si vous en ajoutez un, choisissez le niveau de correction le plus élevé, gardez le monogramme petit et testez la carte imprimée avec plusieurs téléphones.

### Le QR code RSVP doit-il ouvrir le formulaire de réponse ou le site ?

L'adresse principale du site est généralement plus sûre. Elle montre les détails aux invités avant qu'ils répondent, correspond à l'adresse écrite et fonctionne encore après la fermeture du formulaire. Veillez à ce que le formulaire soit facile à trouver dès le premier écran.
