# Velvet Jewel Box

Rebuilt from the current Blush Garden Rose five-page framework on 2026-10-18 at the user's request.

Opening, Home, Story, Details, RSVP, editable copy/photo slots, optional blocks, reduced motion, keyboard opening, replay, calendar and thank-you mode use the same framework. The generated theme-specific background and existing cover are real raster artwork; the open envelope is generated from the same cover, and its layers are technically cut.

The demo uses shared fictional Blush Garden Rose sample photos where its record has no image. Buyer records retain their own media.

See [the QA report](../../../docs/qa/2026-10-18-eleven-designs.md) for the validation scope and results.

The prior interim build_images.py describes the superseded concept kit; it is retained as history and is not the source of the current generated release assets. Use the production images, envelope-geometry.json and the recorded image prompts for further edits.
