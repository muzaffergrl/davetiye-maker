# Crimson Rose Atelier

Independent new wedding website theme, not a Burgundy Velvet Autumn replacement.

Five pages: a burgundy wax-sealed envelope opening, an invitation with an offset oval portrait, a manual landscape chapter album, a typographic programme, and an ivory reply card on oxblood.

Content uses the current platform engine's data-field/data-copy/data-photo/data-repeat/data-map contracts. The shared RSVP form script supplies ten custom questions, all five answer types, party names and required/optional fields. Audio uses the shared platform script. Advanced panel/backend capabilities remain shared platform responsibilities.

Photo slots: hero_portrait 4/5; story_1, story_2, story_3 4/3; venue 16/9. Names, dates, captions, photos and links are never baked into production artwork.

Opening timings: seal 0ms; flap 400ms; card 1600ms; forward cue 3000ms; navigation 3350ms. Reduced-motion path: 100ms. The shared fallback sound cues match those timings. DESIGN_SOUND registers Evening Strings for buyer-created sites; the demo record selects the same track.

All artwork was created with built-in image_gen. Source PNGs and English prompts live in collections/21_Crimson_Rose_Atelier/assets/gpt/. WebP derivatives preserve source transparency. Open-envelope body alignment uses X scale 1.14, Y scale 1.247, offset -6.9%/-34.2% to compensate for generation drift. This is technical alignment of generated material, not CSS-drawn decoration. The layout intentionally uses a simple oval photo crop instead of the concept board's gold oval frame, and a paper album instead of a literal leather book.

State: demo-ready product added on codex/crimson-rose-atelier after user approval; sale remains pending. Current checks: 35 engine/content checks and 75 Chrome browser checks passed. Browser assets were fulfilled from local files due to network restrictions; external web fonts were replaced by their CSS fallbacks during those screenshots. Real phones, live hosting, actual guest persistence and real Google OAuth were not tested for this new product.
